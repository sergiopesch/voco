# VOCO 2026.0.59

Keep Alt+D available when GNOME rejects an outdated Stop reservation. The companion
now releases the shortcut immediately after the latest request is rejected. Late
replies from older renewals cannot release a newer accepted reservation.

Reservations now follow the capture session and exact shortcut, so status updates
cannot discard a held Stop. Explicit Stop keeps that session identity through
native dispatch and renderer admission, rejecting a delayed request for a replaced
recording. Forced status-update races are covered in real GNOME regressions.

This follows the Brave text-preservation fixes in 2026.0.58. Companion version 4
lets setup detect an older loaded copy; follow any sign-out/sign-in guidance to
activate the correction. No input permissions or recognition model/runtime change.

Installer cleanup now belongs only to its original process. Stopping a background
progress task before it initializes cannot remove parent files or stop parent jobs;
early shutdown diagnostics stay in the private log and leave the logo canvas intact.

The regression runs in a private real GNOME session and checks both rejection
cleanup and out-of-order replies. The published package and supported platforms
remain recorded in [release status](../release-candidate.md) until qualification
and signed publication complete.
