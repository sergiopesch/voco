# VOCO 2026.0.43

Native Linux packages and more reliable desktop dictation, with one shared local
English recognition model.

This release is being qualified. It is not yet a public download; follow
[release status](../release-candidate.md) for availability.

## What changes

- Separate Debian, Fedora, openSUSE and Arch packages declare their native
  dependencies. Omarchy uses the Arch package with documented Hyprland setup.
- Wayland microphone capture uses the native audio backend, allowing a genuinely
  hidden panel and fresh recording without a transparent tiled window. Select a
  microphone and permit access for the current app session; setup itself does not
  record. A lost source requires explicit selection again.
- `voco --toggle` supports desktop-managed Start/Stop shortcuts. It queues one
  request to the running app without grabbing focus or reading keyboard devices.
  The installation guide explains modifier-aware compositor bindings.
- Recognition leaves one CPU from process affinity for desktop work, using at
  least one thread and at most four. Audio IPC batches 100 ms instead of 20 ms,
  reducing requests from 50 to ten per second. Stop immediately flushes the tail;
  the three-second backlog limit and sample accounting remain unchanged.
- Desktop delivery requires a verifiable destination. GNOME X11 decorations are
  distinguished from actual recipients; an unknown destination cannot authorize
  an unguarded paste. Changing focus retains recovery rather than continuing into
  another field.
- Firefox text and caret updates may arrive separately. Exact expected text at a
  known prior caret remains pending until position agrees, within the existing
  deadline. An uncertain paste is never automatically replayed.
- Debian upgrades repair the known inherited package-directory permissions while
  preserving custom permissions and user settings. Native packages preserve
  required model and dependency licenses, including minimal-documentation RPM
  installs. Desktop notification commands are explicit dependencies.

The selected model and context are unchanged. This is not a new accuracy claim.
The 20-chapter [code guide](../guide/README.md) explains the architecture, observed
failures, fixes and qualification boundaries. TypeSafe remains optional research
for approved public or synthetic text; it is not a network dependency of VOCO.
No new TypeSafe semantic score is claimed for these package and desktop changes.

## Evidence and limits

The [dated qualification report](../testing/linux-release-2026-09-19.md) retains
attempts and source identities. It includes booted Ubuntu GNOME, Fedora GNOME,
openSUSE KDE and packaged Omarchy/Hyprland guests, plus separate container package
checks. A container does not establish a distribution's desktop behavior.

The final packages delivered 1,162/1,162 normalized words over 577.68 seconds
in both Omarchy's GTK recipient and openSUSE KDE's Firefox recipient. Stop-to-idle
was 922 ms and 376 ms respectively. Firefox had settled for 60 seconds and used
no growing DOM diagnostic log. The Omarchy audit matched all 25,505,676 retained
audio frames to native capture; independent waveform alignment covered the entire
fixture. These are individual VM observations, not latency percentiles or physical
microphone results. The dated report identifies the final application hash and
separates earlier candidates and failed harness attempts. A separate ten-minute
Fedora GNOME run delivered all 1,162 words with complete native/renderer sample
parity, but took 2,813 ms to reach idle after Stop. This remains an explicit
responsiveness limitation of the constrained guest, not a sub-second claim.
The final Ubuntu GNOME X11 long run also delivered all 1,162 words, with a
367 ms Stop-to-idle observation. Across final-package desktop qualification,
21 scenarios completed; four additional harness/setup failures were preserved
and corrected without application changes.

Twelve public speech fixtures contain 238 reference words and six lexical edits
(2.52% normalized WER) across the tested worker controls. Their final transcripts
match the earlier default exactly. This small corpus does not establish accuracy
across accents, noise, terminology or worldwide use. Punctuation references and
screen-paint timing need independent annotation.

On a constrained two-vCPU guest, concurrent Firefox startup caused bounded audio
backlog failures; those failures remain recorded. Leave enough CPU capacity for
both recognition and the receiving application. VOCO preserves available recovery
rather than allowing unbounded audio delay.

Physical microphones, suspend/resume, arbitrary applications, every desktop
variant and every Linux distribution remain outside this qualification. Packages
require x86-64 with AVX2/FMA/F16C, glibc 2.39+ and compatible libstdc++. Wayland
paste needs a configured input daemon and clipboard helper; package installation
does not grant broad device permissions. Flatpak, Snap and AppImage are not
published channels. Prior public releases remain available for rollback.
