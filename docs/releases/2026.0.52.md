# VOCO 2026.0.52 — An installation that follows the work

This Ubuntu/Debian x86_64 cut adds measured VOCO installer progress and removes
avoidable download overhead. Publication and downloadable assets are authoritative
on [GitHub Releases](https://github.com/sergiopesch/voco/releases/tag/voco.2026.0.52).
Until publication is verified, the README continues to point to public .51.

- Signal bars follow recent measured transfer rates. A brief silver sweep marks
  phase changes; installation never waits for animation to finish.
- Release checksums download alongside the package, and verification remains
  mandatory before installation. Unfinished optional Wayland-helper prefetches
  defer to the final APT transaction.
- The installer waits directly on its downloader, avoiding a 250 ms polling delay.
  Rendering uses bounded updates and fewer helper processes, with no new UI package.
- APT progress stays in the VOCO view where supported. Native passwords, package
  questions, configuration choices and unexpected output remain visible. Systems
  without Python or with restricted sudo policies retain ordinary APT output.
- GNOME reduced motion, `VOCO_INSTALL_NO_MOTION=1`, `VOCO_INSTALL_PLAIN=1`,
  `NO_COLOR`, redirected output and basic terminals retain appropriate fallbacks.

The app is rebuilt with .52 version metadata. Dictation behavior, model and native
speech runtime remain unchanged from .51. The measured tray, connected microphone
setup, packaged GNOME companion and single Nemotron recognizer are retained.

## Install and upgrade

After this release is published, use its exact installer:

```bash
wget -qO voco-install https://raw.githubusercontent.com/sergiopesch/voco/voco.2026.0.52/install && bash voco-install
```

Quit VOCO and save any recovery text before upgrading. An ordinary upgrade
preserves microphone, shortcut and onboarding settings. A fresh-user test requires
archiving the existing profile separately; package removal alone does not reset it.
Use the [installation guide](../install.md) for manual installation and publisher
signature verification. Fedora, openSUSE and Arch/Omarchy stay at **2026.0.43**.

## Verification and limits

The [installer comparison](../testing/installer-performance-2026-09-22.md) records
56 successful local download trials and real Ubuntu APT prompt tests. The paced
animated download fixture was about 24% shorter and used 26% less CPU than its
baseline. Those are local download-path measurements, not whole-install or
Internet speed guarantees. The measurements use the exact .52 installer after its metadata bump.

Final source CI, rebuilt package checks and signatures must pass before publication.
The release validation/provenance assets will identify their exact commits and
hashes. Earlier [.51 desktop evidence](../testing/tray-setup-2026-09-21.md) retains
its original build identity; it does not become exact-byte evidence for this rebuild.
Physical microphones and the wider compositor/application matrix remain separately
qualified. No new accuracy or universal speed claim is made.
