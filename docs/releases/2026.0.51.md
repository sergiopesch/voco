# VOCO 2026.0.51 — Live voice feedback

This Ubuntu/Debian x86_64 release combines the .48–.50 improvements with a live
tray meter, connected microphone setup and one bundled recognition engine.
Publication and downloads are authoritative on
[GitHub Releases](https://github.com/sergiopesch/voco/releases/tag/voco.2026.0.51).

- Pressing Alt+D replaces Ready with bars driven by microphone volume. The bars
  respond quickly to speech, settle during silence and return to Ready after Stop.
  Native tray images remain valid for the app's lifetime. The GNOME companion
  follows the same measured levels and respects system reduced motion.
- Change microphone stays inside the voice-test canvas. Applying a microphone
  returns to Start test; failed selection stays visible and never starts recording.
  Help and completion fit the minimum window at normal text size, while enlarged
  accessibility text can still scroll.
- Desktop dictation, Chromium exact-field delivery and recovery use the bundled
  NVIDIA Nemotron English model. The retired recognizer, downloader, vendor code
  and dependencies are removed; a regression gate prevents their return.
- GNOME Shell 46 panel files are bundled. Setup offers explicit activation and
  reports when a session restart is needed. Package installation never enables
  extensions automatically. Reopening VOCO shows the existing idle app.
- Rich-editor delivery waits for matching text and caret observations. Uncertain
  output remains recoverable instead of being replayed. Desktop setup readiness
  is checked separately from the cursor in the receiving application.

## Install and upgrade

Run the versioned guided installer:

```bash
wget -qO voco-install https://raw.githubusercontent.com/sergiopesch/voco/voco.2026.0.51/install && bash voco-install
```

Alternatively, use the [versioned Debian package](../install-native.md) with its
signed checksum manifest. Quit VOCO and copy any needed recovery
text before upgrading. Microphone, shortcut and onboarding preferences are
preserved. The bundled model is unchanged; no separate model download is needed.

Fedora, openSUSE and Arch/Omarchy packages remain at **2026.0.43**. CPU and system
requirements remain x86_64 with AVX2/FMA/F16C and glibc 2.39 or newer.

## Verification and limits

The [combined qualification record](../testing/tray-setup-2026-09-21.md) records
449 frontend tests, 283 Rust test executions, renderer checks, 13 packaged-worker
protocol cases, clean Ubuntu installation/removal and isolated desktop/audio
journeys. All four protected CI checks passed on the PR and merged release source.
The [public release record](../testing/linux-release-2026-09-22.md), signed
provenance and validation assets identify the final package and its exact scope.

The release preserves the qualified application, browser host, runtime and model
bytes; final package metadata and bundled documentation are refreshed separately.
Virtual audio and nested desktops do not qualify physical microphones, perceived
motion on every panel or every compositor/application. No broader performance or
accuracy claim is made. Audio remains local; no account or telemetry is added.
