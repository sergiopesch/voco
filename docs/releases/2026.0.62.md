# VOCO 2026.0.62

Dictation is the first step. We're building the voice layer for Linux: private,
local, and under your control.

**Today: private dictation for Linux.** Press a shortcut, speak, and your words
appear where you are typing, while you speak.

This release introduces that message, makes dictation safer around the lock
screen and the network, and brings VOCO's app framework and build tools up to
date. It runs on the same systems as 2026.0.61: Ubuntu 24.04 and 26.04, Debian 13
and Fedora 44. The [changelog](../../CHANGELOG.md) lists every change.

## What's new

- **The voice layer for Linux.** The installer, the README and the package
  descriptions now introduce VOCO this way, and its desktop entry gains search
  keywords such as "dictation" and "voice".
- **Locking the screen stops dictation.** VOCO shows **Dictation stopped**, and
  words it hadn't typed go to the clipboard. While the screen is locked, VOCO
  sends no keys and its shortcut doesn't start dictation.
- **The speech worker can't open network sockets.** A filter refuses every socket
  except a local one, and the worker's Python ignores `PYTHON*` variables and
  your own site-packages.
- **Update checks when you choose.** On the **Updates** page, set
  **Update checks** to **Only when I choose**, and VOCO asks GitHub about
  releases only when you choose **Check for updates**.
- **Only Shift and Insert.** The space between phrases is now pasted with the
  words instead of pressed as a key, so VOCO's keyboard can press only
  Shift+Insert. A Space key press can activate a focused button or checkbox; a
  paste can't. A terminal still passes pasted text, spaces included, to the
  program running in it.
- **The GNOME panel on GNOME 51.** The panel now loads on GNOME 51 as well as 46,
  48 and 50.
- **The engine benchmark.** The [report](../../research/engine-benchmark-2026-10/README.md),
  its harness and every run's results show why VOCO keeps Nemotron English at a
  160 ms step.
- **Dependencies.** Tauri 2.12.2, with tray-icon 0.25.1 and VOCO's patch for fixed
  tray icon files, and Vite 8.3.3. The packages are built with Rust 1.99.0 and
  Tauri CLI 2.12.1. The speech model and the GNOME panel's code are unchanged.

## Upgrade

Use these steps once the
[2026.0.62 release page](https://github.com/sergiopesch/voco/releases/tag/voco.2026.0.62)
lists the signed packages.

1. Finish any dictation, and copy anything you need from Review.
2. Quit VOCO with **Quit VOCO** in the tray menu. The GNOME panel has no quit item,
   so with the panel run `pkill -x voco`.
3. Run this release's guided installer, or repeat the
   [manual install](../install.md#manual-install):

   ```bash
   wget -qO voco-install https://raw.githubusercontent.com/sergiopesch/voco/voco.2026.0.62/install && bash voco-install
   ```

Your settings are kept. On GNOME 46, 48 and 50 the GNOME panel's code is the
same as in 2026.0.61, so you don't need to sign out and back in. On GNOME 51,
choose **Enable live panel** on the **Help** page, or run `voco --setup-panel`,
then sign out and back in.

## Known limits

- Dictation replaces what the clipboard and the primary selection hold.
- On Wayland, session checks are not an atomic lock: switching sessions after a
  check can still redirect keys. An unavailable logind status permits pasting.
  See the [input-device security model](../security/README.md#input-devices).
- GNOME's own microphone indicator can still shift the top bar's icons while the
  microphone is in use.
- On Debian 13 and Fedora 44, VOCO has an icon in the top bar only once the GNOME
  panel is on, because they don't turn on an AppIndicator extension.
- DNF says it skipped OpenPGP checks for the RPM file. The installer verifies the
  signed checksums first, which is what authenticates the package.
- VOCO discards a recording it can't confirm is complete, and says so at Start.
- VOCO can't tell a password field from other fields. Don't dictate into one.
- Don't dictate while a terminal program is waiting for an answer, such as a
  coding agent's permission prompt: it may read your words as typed keys. See
  [Where your words go](../everyday-use.md#where-your-words-go).
- In Chromium's address bar, a phrase that continues the previous one joins its
  last word, because the address bar trims the pasted space.
- VOCO knows the screen is locked only when the desktop reports it to logind, as
  GNOME does.
- Apps that remap Shift+Insert, remote desktops and virtual machines may not
  accept the paste. Custom editors and other compositors need their own testing.
- On Wayland, a shortcut other than Alt+D or Alt+Shift+D works only when you bind
  it to `voco --toggle` in your desktop's keyboard settings. VOCO no longer
  registers it through XWayland.
- VOCO recognizes English only. It needs x86-64 with AVX2, FMA and F16C, and
  glibc 2.39 or later.
