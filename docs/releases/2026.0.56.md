# VOCO 2026.0.56

Unpublished candidate. Use only assets attached to a verified published release.

The guided installer opens VOCO after package installation and desktop setup
succeed. The launch runs as the installing desktop user and outlives the installer
terminal. Remote, root and headless sessions retain manual instructions. Opening
VOCO does not start microphone capture or complete onboarding.

Ghostty 1.3.1 on Linux exposes its terminal pane as a graphical canvas rather than
an accessible text field. Version .55 consequently refused to start dictation
there. This candidate recognizes the focused terminal pane, binds delivery to its
identity and revokes that binding when focus leaves or the pane changes. Ordinary
Ghostty text fields keep the standard paste shortcut.

Terminal paste never sends Enter or terminal control characters. A focused pane
does not establish that a terminal is writable, at a shell prompt or outside a
password reader. Terminal delivery confirms dispatch, not text readback. Stop
dictation before switching destinations and review text before submitting it.

Destination rejection also previously cleared microphone readiness even though
capture had not started. This candidate preserves the approved microphone when
destination or desktop setup checks fail; actual microphone startup failures still
invalidate readiness.

The pinned local recognizer, model, input permissions and recovery behavior are
unchanged. Source, private desktop, complete-package and public-release checks are
separate gates; candidate status is not a release or universal compatibility claim.
