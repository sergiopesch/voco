# VOCO 2026.0.46 — Wayland installation and readiness

This is an unpublished Ubuntu/Debian candidate. Public downloads remain at .45
until a separately verified release is published. Fedora, openSUSE and Arch assets
remain at .43; dependency profile changes do not requalify those packages.

The .45 short installer could finish without installing the Wayland input helpers.
Its local voice test could then pass while every cursor-dictation attempt was
rejected before capture. The candidate fixes that installation/readiness gap.

- Install the local package through APT and explicitly require `ydotool` and
  `ydotoold` on Wayland. Declare the process-query dependency used by diagnostics.
- Reuse a working input daemon, or start the supplied per-login service when
  device access already exists. Preserve other services and device permissions.
  Exit with incomplete-setup status when desktop input remains unavailable.
- After draining a successful voice test, check input prerequisites before saving
  onboarding completion. Missing helpers, stopped/inaccessible daemons and failed
  or timed-out checks keep setup open, with a retry and setup-instructions action.
- Distinguish incomplete desktop setup from an unverified cursor. Neither case
  permits unguarded recording/paste. Onboarding itself needs no external cursor.
- Add `voco --check-desktop-input`, sharing the app's bounded prerequisite check
  without launching its interface or injecting keys.
- Correct the cursor-dictation instructions and update installation, removal,
  troubleshooting, architecture and the local learning guide.

## Limits

The installer does not grant raw keyboard access, change `/dev/uinput` permissions
or overwrite an existing daemon. New accounts may need owner-approved device
setup and a compositor shortcut. A ready input helper does not prove an application
has an accessible cursor; a passing voice test does not qualify every microphone.

See the [verification record](../testing/wayland-install-2026-09-20.md) for executed
checks and evidence boundaries. No recognition model, worker thread count or
speech quality parameter changes are included.
