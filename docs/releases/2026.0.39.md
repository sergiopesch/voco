# VOCO 2026.0.39

Public release. Local English dictation for Linux, streaming to the cursor.

This cut backports the upstream glib iterator safety fix
([RUSTSEC-2024-0429](https://rustsec.org/advisories/RUSTSEC-2024-0429)) to the
shared 0.18.5 dependency used by GTK/WebKit. Dictation-only UI, NVIDIA Nemotron
English 0.6B Q8 CPU, and streaming delivery are unchanged from the accepted
dictation-only app.

The package is amd64. Isolated delivery tests and package install/remove passed.
They do not prove every Linux desktop, compositor or application. Checksums
verify integrity, not publisher identity.

Hosted GitHub Actions did not build this installer. Later product-code changes
require a new version. Previous public release `voco.2026.0.21` remains available
for rollback.
