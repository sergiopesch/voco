# VOCO 2026.0.53

Published Ubuntu/Debian x86_64 dependency maintenance release. It retains the
Signal + Silver sweep installer, live tray bars, compact microphone setup and
pinned local Nemotron recognizer.

This cut integrates dependency PRs #46–#57. The app and shortcut plugin share the
updated, patched X11 keyboard actor. Input-event handling and SHA-256 formatting
retain their existing contracts. The directory/build dependencies, Geist Mono
font and frontend tools are refreshed. TypeScript 7 uses Microsoft's supported
API compatibility package for ESLint and compiler-API tests.

Use the exact published installer:

```bash
wget -qO voco-install https://raw.githubusercontent.com/sergiopesch/voco/voco.2026.0.53/install && bash voco-install
```

[Signed release assets](https://github.com/sergiopesch/voco/releases/tag/voco.2026.0.53)
and [exact-package qualification](../testing/dependency-release-2026-09-22.md)
record source identity, tests, preserved attempts and limits. The signatures,
downloaded assets, latest aliases and tagged installer have been verified.

Compatible dependency updates are now grouped weekly, with two open version PRs
per ecosystem. Major/input updates remain separate, merged branches are removed
automatically, and protected checks remain mandatory. Subsequent grouped updates
are a separate review batch. See [repository maintenance](../release-process.md#repository-hygiene).

[2026.0.52](2026.0.52.md) remains available for rollback. Other native package
channels remain at .43. Physical-microphone and broader desktop acceptance remain
separate from the isolated .53 checks.
