# VOCO 2026.0.53

Qualified dependency maintenance candidate. Publication is pending; [2026.0.52](2026.0.52.md) remains the public installer until those checks finish.

The app retains the Signal + Silver sweep installer, live tray bars, compact
microphone setup and pinned local Nemotron recognizer. This cut updates the
keyboard input, shortcut, checksum, directory and build dependencies, plus the
Geist Mono font and frontend development tools.

The shortcut plugin and VOCO share one patched `global-hotkey` 0.8 actor,
retaining X11 focus leases. evdev 0.13 keeps exact modifiers, key-repeat rejection,
unplug cleanup and dropped-event resynchronization. SHA-256 values retain their
lowercase, zero-padded format. TypeScript 7 uses Microsoft's API compatibility
package for ESLint and compiler-API tests.

Dependency PRs are grouped weekly when compatible; major updates and sensitive
input dependencies remain independently reviewable. Merged branches are deleted
automatically. Required checks and the disabled hosted release assembler are retained.
