# VOCO 2026.0.37 — private release cut

Owner approval: 15 September 2026, following successful installed +local7 English
dictation. Public release remains withheld until final artifact benchmarks and
explicit publication approval. The application is local-first Linux dictation
using NVIDIA Nemotron Speech Streaming English 0.6B Q8 on the CPU.

## Frozen scope

The cut promotes accepted +local7 application/model/helper bytes, without changing
recognition, UI, shortcuts, privacy, settings or dependencies. Canonical Debian
metadata is `2026.0.37`; the running owner candidate remains `2026.0.37+local7`.
Debian sorts +local7 above the canonical version, so moving that test machine to
the exact cut later is an explicit version downgrade, not a failed update check.
Do not reinstall during release preparation or change model/runtime bytes to make
packaging more convenient. Exact commit, archive and asset hashes live in the
external cut manifest to avoid self-referential package/source hashes.

Changes since the previous public release include streaming desktop delivery,
conservative focus/recovery handling, sampled accessible-field observation,
Stop-tail delivery, scoped X11 shortcut ownership, event-driven shortcut waiting,
worker recovery, bounded private metrics and the documented Crystal Sidebar UI.
The last production optimization only makes legacy ydotool's delay explicit,
retaining its key events and nonzero spacing. No whole-message rewriter was added.

## Evidence carried into the cut

The accepted source passed 498 Rust test executions, 459 frontend tests (two
optional replay skips), the full npm regression chain, static checks and a
production build. +local7 additionally passed 64 real-helper trials, eight private
recipient cases and four exact-package NVIDIA/X11 app cases. A fresh Ubuntu
install/remove check verified 181 payload objects and nine ELF objects. Previous
+local6 Stop coverage was 34 selected cases from 35 attempts; it is historical
coverage, not 34 reruns of the cut. Source and runtime parity receipts establish
which evidence applies; metadata and packaged-doc changes need their own checks.

The latest owner recording lasted 56.718 seconds and completed 87/87 dispatched
deliveries with reconciled sample counters and no recorded failures/dropped logs.
Median keyboard dispatch was 66 ms and total dispatch 108 ms. First completed
dispatch was 1.468 seconds from recording start; Stop-to-final was 174 ms.
These are one session's observations, not controlled acoustic latency, independent
cursor paint, a word-error-rate score or a universal performance guarantee.
No owner audio/transcript is included in public-facing source or release assets.

## Draft assets and verification

The draft contains the complete versioned Debian archive, a byte-identical latest
alias, corresponding SHA-256 lists, source/runtime provenance and these release
notes. Verify hashes after downloading. The exact application ELF, browser/input
helpers, native libraries and model must match the accepted package. All bundled
licenses/notices and dependencies remain required. A plain Tauri archive omits
NVIDIA and must never be attached as the complete app. AppImage, Snap, Flatpak,
RPM and Arch binaries are not release assets for this cut.

## Explicit remaining public gates

- Final benchmarks run against the downloaded frozen cut and record exact artifact,
  installed executable/model, hardware, sample counts, repetitions, failures and
  stage timing origins. Retain 30 s, 90 s and 5 min speech workloads; distinguish
  cold/warm starts and observable recipient changes from dispatch receipts.
- Current-revision target-app/default-desktop and long-duration physical coverage
  remains bounded. Ubuntu is the reference; distro userspace/container results
  are not a qualified Omarchy/Hyprland, GNOME or KDE desktop matrix.
- This runtime is host-native CPU code. Portable, pinned NVIDIA artifact
  provisioning and CPU compatibility qualification are incomplete. The current
  tag-triggered hosted build therefore is not the cut's creation mechanism.
- The intended public product is dictation-only; deferred assistant/integration
  paths still exist in the accepted build. Their disposition is a separately
  tested product milestone, not a silent change to this cut.
- Retain documented dependency maintenance/unsoundness notices. Fresh audits are
  required for this source commit; zero vulnerability-class results are not a
  universal security claim. No waivers or relaxed Whisper criteria are permitted.
- English is the selected pipeline. Automatic Spanish/multilingual switching and
  post-Stop whole-message rewriting are not supported by the generic route.
- Public tagging/channel activation and publication require final owner approval.
