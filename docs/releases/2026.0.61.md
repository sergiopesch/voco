# VOCO 2026.0.61

VOCO types on Wayland through its own virtual keyboard, so there is no input
service to set up, and it supports Ubuntu 24.04 and 26.04, Debian 13 and Fedora 44.
This release also brings the changes prepared for 2026.0.60, which wasn't
published. The [changelog](../../CHANGELOG.md) lists every change.

## What's new

- **Four systems.** Ubuntu 24.04 LTS and 26.04 LTS and Debian 13 install the
  Debian package with APT; Fedora 44 installs `voco-2026.0.61-1.x86_64.rpm` with
  DNF. The guided installer picks the right one.
- **A virtual keyboard of its own.** On Wayland VOCO presses Shift+Insert through
  "VOCO virtual keyboard". The package's udev rule lets the person at the computer
  use it, with no daemon, service or `input` group. VOCO types only while your
  session is the active one.
- **Paste into focus.** VOCO puts each phrase on the clipboard and the primary
  selection, then presses Shift+Insert, so terminals, browsers and native text
  fields take the same path. Switch windows and the next phrase goes to the new
  one. VOCO never presses Enter.
- **Words kept when a paste fails.** VOCO says it stopped typing and keeps
  listening. At Stop it copies the words it didn't type to the clipboard; check
  the field first, as some may already be there. If the copy fails too, the
  dictation goes to Review.
- **Review.** If VOCO closes unexpectedly while you dictate, the next start keeps
  the text in Review, in the tray menu or the GNOME panel menu, with
  **Copy transcript** and **Discard**.
- **GNOME companion 15** for GNOME 46, 48 and 50. The panel is one pill that shares
  GNOME's highlight, and the microphone stays still while the live bars open on
  its left. Click it to stop dictation or open Settings, or right-click it for
  Settings, Review and Stop dictation. On Wayland it keeps Alt+D and Alt+Shift+D
  out of the app you're typing in.
- **Clearer status.** With no microphone chosen VOCO reads "Ready · microphone
  checks on first use" and Start uses your default microphone. VOCO tells you when
  your shortcut can't reach it, when it has no icon in the top bar, and, if a
  recording stops before any words, that nothing was typed.
- **Dependencies.** Tauri 2.11.6 and Vite 8.3.1. The speech model and the speech
  runtime are unchanged.

## Upgrade

1. Finish any dictation, and copy anything you need from Review.
2. Quit VOCO with **Quit VOCO** in the tray menu. The GNOME panel has no quit item,
   so with the panel run `pkill -x voco`.
3. Run this release's guided installer, or repeat the
   [manual install](../install.md#manual-install):

   ```bash
   wget -qO voco-install https://raw.githubusercontent.com/sergiopesch/voco/voco.2026.0.61/install && bash voco-install
   ```

4. On GNOME 46, 48 or 50, run `voco --setup-panel`, which the guided installer
   also runs. Then save your work and sign out and back in, so GNOME loads
   companion 15 and your session gets access to the virtual keyboard.

Your settings are kept. VOCO drops the output settings it no longer uses the next
time it saves them.

If you upgraded to Ubuntu 26.04 and VOCO stopped starting with a message about a
pending transition, install this release: on its first start VOCO retires its old
input service, which it no longer needs. The `ydotool` package and its own
service, if you installed them, are no longer used by VOCO.

## Known limits

- Dictation replaces what the clipboard and the primary selection hold.
- GNOME's own microphone indicator can still shift the top bar's icons while the
  microphone is in use.
- On Debian 13 and Fedora 44, VOCO has an icon in the top bar only once the GNOME
  panel is on, because they don't turn on an AppIndicator extension.
- DNF says it skipped OpenPGP checks for the RPM file. The installer verifies the
  signed checksums first, which is what authenticates the package.
- VOCO discards a recording it can't confirm is complete, and says so at Start.
- VOCO can't tell a password field from other fields. Don't dictate into one.
- Apps that remap Shift+Insert, remote desktops and virtual machines may not
  accept the paste. Custom editors and other compositors need their own testing.
- VOCO recognizes English only. It needs x86-64 with AVX2, FMA and F16C, and
  glibc 2.39 or later.
