# VOCO 2026.0.60

Source candidate; no signed installer has been published for this version.

Desktop dictation now pastes each chunk into whatever app has keyboard focus.
VOCO copies it to the clipboard and primary selection, then presses Shift+Insert;
it never presses Enter. If typing is interrupted, VOCO stops typing and keeps
listening; at Stop it copies the words it did not type to the clipboard. Uncertain
output is never replayed as keys. After an unexpected exit, tray Review offers the
saved text.

Tray, popover and notification wording now describes what VOCO actually did. At
launch the tray reads "VOCO — Initializing…" until desktop setup has been checked,
instead of briefly warning that setup is needed. A notification appears once
instead of repeating at Stop. Review takes keyboard focus when it opens, and Copy
also sets the primary selection for terminals.

Remove two unused streaming implementations, the unreachable second recognition
pass over retained audio, IBus text mutation and their obsolete tests; production
recognition and delivery continue through the existing phrase queue. While idle,
native capture, panel checks, the IBus listener and the launcher reaper wake less
often. The window no longer re-renders for every audio level, recognition update
or unchanged diagnostics poll. Shell validation now checks every supplied script,
including release checks.

Refresh Vite to 8.3.1 and Tauri to 2.11.6, preserving one renderer dependency
resolution and the existing GLib, tray and shortcut backports. The bundled speech
model/runtime and input permissions are unchanged.

The GNOME companion is now version 12. On GNOME Wayland it keeps Alt+D and
Alt+Shift+D out of the focused app at every status, idle included. Its meter opens
on the microphone's left instead of pushing the microphone aside; GNOME's own
privacy indicator can still shift panel icons while the microphone is in use.
After upgrading, run panel setup again, then sign out and back in so GNOME loads
the new version.

Personalisation remains a [proposal](../architecture/personalisation-plan.md).
It is not enabled in this candidate.

[Qualification status](../testing/release-2026.0.60.md) distinguishes source CI
from the package, installation and signing checks still required. The recorded
public Ubuntu/Debian installer remains 2026.0.59 until those checks are complete.
