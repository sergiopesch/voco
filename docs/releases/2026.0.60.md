# VOCO 2026.0.60

Source candidate; no signed installer has been published for this version.

Desktop delivery can now keep checking the same verified destination when its
accessibility content and caret positions update separately after a paste. The
original deadline still applies. A definite regression rejects delivery, and
uncertain output is never replayed. Admission and pre-dispatch checks stay strict.

Remove two unused streaming implementations and their obsolete tests; production
recognition, delivery and recovery continue through the existing phrase queue.
Shell validation now checks every supplied script, including release checks.

Refresh Vite to 8.3.1 and Tauri to 2.11.6, preserving one renderer dependency
resolution and the existing GLib, tray and shortcut backports. The bundled speech
model/runtime, input permissions and GNOME companion version 4 are unchanged.

Personalisation remains a [proposal](../architecture/personalisation-plan.md).
It is not enabled in this candidate.

[Qualification status](../testing/release-2026.0.60.md) distinguishes source CI
from the package, installation and signing checks still required. The recorded
public Ubuntu/Debian installer remains 2026.0.59 until those checks are complete.
