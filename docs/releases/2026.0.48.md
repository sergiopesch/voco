# VOCO 2026.0.48 — local test candidate

This candidate addresses the fresh-install issues reported on 21 September.
It is not yet a published GitHub release. Public installation instructions remain
pinned to .47 until a separately qualified release is published.

- Onboarding keeps the recording button and meter inside one capsule, with a single
  keyboard focus outline and the original VOCO microphone icon.
- Notifications keep their D-Bus sender alive so GNOME can display them. They use
  VOCO's icon, respect desktop notification settings and record finite transport errors.
- Missing Wayland helper downloads overlap the main package transfer. Completed
  APT-verified downloads are reused during installation; failures fall back to APT.
- Download completion includes elapsed time, and the package staging directory
  permits APT's unprivileged reader. Zstandard level 9 slightly reduces download size.
- Cursor diagnostics distinguish rejection causes. `voco --check-cursor` checks the
  focused field without recording or typing; notifications explain missing app accessibility.

The English model, recognition settings and installed model size are unchanged.
Chromium/Electron apps may require [accessibility activation](../install.md#chromium-and-electron-applications)
and a full restart. The local Codex/Brave launcher adjustments are host setup,
not automatic installer behavior or proof of every editor's compatibility.

Measurements and verification boundaries are in the [fresh-install investigation](../testing/fresh-install-2026-09-21.md).
