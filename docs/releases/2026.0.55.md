# VOCO 2026.0.55 — candidate

**Unreleased.** Public downloads and the owner's installed app remain 2026.0.54.

- Brave address-bar suggestions preserve the verified typing destination instead
  of stopping after a successful first paste. Real focus changes still stop delivery.
- Cold input discovery reaches visible fields before hidden suggestion contents,
  within the existing bounds. An unfocused terminal pane cannot change an editor's
  paste shortcut.
- WebKit input discovery continues through focused web-view containers to the
  actual input. Password controls remain rejected.
- Desktop delivery rechecks its destination after clipboard preparation and before
  sending paste keys. Stop dictation before changing fields; an in-flight keyboard
  gesture still cannot provide atomic field ownership.
- Empty editable HTML blocks can lose their placeholder line break when text
  arrives. Readback now handles that without changing native/plain-text newlines.
- The installer keeps Signal + Silver progress in one canvas, clears completed
  frames and handles password/package prompts without scattered status blocks.
- The guided installer requires a verified publisher signature on its checksum
  manifest before package installation; the manual install instructions use the
  same signed release boundary.
- The focus helper runs Python in isolated mode. The unused unguarded insertion
  IPC command is removed; normal bound desktop paste remains.
- Browser tab close, navigation and native connection loss request Stop for that
  browser recording. VOCO retains the exact Stop until its frontend acknowledges
  it; stale browser tokens cannot stop an onboarding test. Ordinary focus loss
  still revokes insertion without redirecting it.
- The local hotkey timing trace is opt-in with `VOCO_HOTKEY_TRACE=1`, private and
  bounded; the separate performance recorder remains opt-in.
- IBus socket cleanup removes only the socket created by that instance, preserving
  a replacement server. Unreachable mutation bodies and unused frontend modules
  are removed while compatibility contracts remain.
- Native Pulse capture requests source latency matching its 10 ms fragments,
  preventing the server buffering that truncated short speech in the isolated
  onboarding trial. Capture ownership and Stop limits remain unchanged.
- The qualified Ubuntu 24.04 legacy input client uses a private, source-built
  daemon with bounded client cleanup. This prevents idle descriptor exhaustion
  and CPU spinning without replacing the distribution daemon or changing device
  permissions. VOCO migrates only its unmodified service while the app is closed.
- Microphone level changes update the meter without rerendering the whole control
  panel. Optional executable hashing uses a fixed 64 KiB buffer.
- Installer configuration honors `XDG_CONFIG_HOME` and preserves settings created
  concurrently. Payload verification rejects unsafe file types, links and modes.

The pinned Nemotron recognizer, capture backend selection, input permissions and
recovery contract are unchanged. Quit VOCO before upgrading. The next installed
Wayland startup can migrate VOCO's own service; custom units and other daemons
remain under their owner's control. For a manual upgrade, run
`voco --setup-desktop-input` while VOCO is closed, then check
`voco --check-desktop-input`. No setup command types into an application.

The [22 September review](../testing/release-readiness-2026-09-22.md) records the
security, performance and cleanup assessment and the superseded pre-helper
candidate. The [23 September qualification](../testing/release-qualification-2026-09-23.md)
records the final helper integration and exact release gates. Earlier package
hashes do not identify this final build. Bundled documents retain their assembly
snapshot; source and published validation manifests record later checks.

Physical microphones, owner-perceived motion and untested desktop/application
combinations remain separate from synthetic fixtures and disposable VM results.
Desktop paste cannot make focus changes atomic with the keyboard gesture: stop
before changing fields. Publisher signatures and verified downloaded assets are
required before publication.
