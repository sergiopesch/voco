# VOCO 2026.0.55 — candidate

**Unreleased.** Public downloads and the owner's installed app remain 2026.0.54.

- Brave address-bar suggestions preserve the verified typing destination instead
  of stopping after a successful first paste. Real focus changes still stop delivery.
- Cold input discovery reaches visible fields before hidden suggestion contents,
  within the existing bounds. An unfocused terminal pane cannot change an editor's
  paste shortcut.
- WebKit input discovery continues through focused web-view containers to the
  actual input. Password controls remain rejected.
- Empty editable HTML blocks can lose their placeholder line break when text
  arrives. Readback now handles that without changing native/plain-text newlines.
- The installer keeps Signal + Silver progress in one canvas, clears completed
  frames and handles password/package prompts without scattered status blocks.

The pinned Nemotron recognizer, audio path, shortcuts and recovery contract are
unchanged. See the [application tests and limitations](../testing/application-delivery-2026-09-22.md)
and [installer evidence](../testing/first-run-follow-up-2026-09-22.md).

A candidate package is not a signed public release. Exact package, CI, publisher
signatures and downloaded-asset checks must be recorded before publication.
