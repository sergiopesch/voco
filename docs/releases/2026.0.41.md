# 2026.0.41 reliability candidate

Private candidate; 2026.0.39 remains the public release. No publication or owner
desktop installation is implied by this record.

- AudioWorklet module or node failure keeps fallback audio for manual recovery
  and never starts automatic NVIDIA delivery.
- Retry transcription for normal dictation uses the bundled local NVIDIA runtime.
  It does not need a Whisper cache or download and never inserts recovered text.
- Cancel retains audio, ignores late results and waits for the private recovery
  worker to be reaped before another retry. Failed recovery remains retryable.
- Successful recovery clears the obsolete Stop recording notice while preserving
  warnings about incomplete capture.
- Package builds pin Whisper CPU options instead of inheriting the builder CPU.

The candidate also includes the previously unreleased lifecycle extraction and
dependency maintenance on master. No model, stack, privacy policy or appearance
change is introduced by this milestone. The private recovery worker temporarily
adds memory use; compatibility/browser paths retain their existing Whisper model
requirements.

See [the architecture decision](../decisions/2026-09-19-local-recovery.md) for
invariants and required checks. Physical microphones, the owner compositor and
owner applications need separate acceptance. Do not infer those results from
renderer tests or isolated X11 fixtures.
