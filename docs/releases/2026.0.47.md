# VOCO 2026.0.47 — Your voice, ready

Release cut for the approved interface and installer improvements, including the
unpublished .46 Wayland readiness fixes. Publication and attached package status
remain authoritative on GitHub Releases.

- A compact voice test with inline microphone selection, live input feedback and
  automatic desktop readiness checks. Your successful test stays available while
  desktop setup is repaired. Done saves only after a final readiness check.
- A concise “Your voice, ready.” handoff, clearer preparation and finishing states,
  keyboard focus transitions and system reduced-motion support. Original VOCO
  microphone branding and graphite materials are preserved.
- Simplified tray controls, microphone settings and a dedicated Shortcut section.
  Alt+D remains the default; existing configured shortcuts are preserved.
- Optional GNOME Shell 46 companion: the branded capsule expands horizontally
  inside the panel. It uses actual status and audio levels, supports reduced
  motion and restores the ordinary tray when detached. Installation is opt-in.
- Installer download byte/speed feedback, quieter checks, bounded retries,
  actionable failures and private diagnostic logs. Static output supports
  NO_COLOR, TERM=dumb and redirected logs. Checksums precede installation.
- Wayland helper dependencies and readiness verification use the installed
  `/usr/bin/voco` binary; an older PATH installation cannot shadow the check.

## Scope

Ubuntu/Debian x86_64 package cut. Recognition model and runtime identity are
unchanged. No cloud transcription, accounts or telemetry are introduced.
The installer does not change device permissions, replace administrator-owned
services or enable desktop extensions. Desktop helper readiness is distinct from
an accessible cursor and physical microphone qualification.

Renderer and nested-desktop fixtures are bounded evidence, not proof of every
Linux distribution, compositor or application. See the release qualification
record and [GNOME companion instructions](../../integrations/gnome/README.md).
