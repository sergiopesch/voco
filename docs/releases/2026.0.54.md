# VOCO 2026.0.54

Published Ubuntu/Debian x86_64 maintenance release.
[2026.0.53](2026.0.53.md) remains available for rollback.

This release updates Tauri, its logging/build dependencies, Geist fonts, React
types and Playwright. Tauri consumes the updated patched tray library, retaining
VOCO's immutable icon paths and measured meter frames. A stronger dependency
gate rejects a second tray version or an unpatched registry copy.

The approved Vite 8 / React plugin 6 migration uses Rolldown/Oxc and Lightning
CSS while retaining the previous explicit JavaScript and CSS output targets.
Development and CI use Node 24 LTS. Future Vite/plugin updates share a dedicated
Dependabot group so their peer requirements receive one review. No application
redesign or recognition-model change is part of this maintenance work.

The combined release passes source/renderer checks, the complete package
verifier, real-model checks and all 12 private GNOME X11 scenarios. Ubuntu APT
installation, installed-file integrity, both real APT prompt cases and 56 local
download trials pass. The exact guided installer installs the final package from
a fresh profile after independent publisher-signature verification. The [qualification record](../testing/vite8-release-2026-09-22.md)
contains exact identities, counts, preserved attempts and limits.

npm reports zero vulnerabilities. Cargo reports no vulnerability-class findings;
its seven unmaintained and one unsound warnings remain visible, as in .53.
The existing patched GLib provenance and regression gate remain required.

All four protected checks passed on the final PR and merged source. The signed
tag, five checksum signatures and all 18 draft/public assets were verified, along
with the latest aliases and tagged installer. The source archive retains its
cut-time qualification record; this repository records subsequent verification.

Use the exact public installer:

```bash
wget -qO voco-install https://raw.githubusercontent.com/sergiopesch/voco/voco.2026.0.54/install && bash voco-install
```

Other native package channels remain at .43. Physical microphone and broader
desktop acceptance remain separate from these isolated checks.
