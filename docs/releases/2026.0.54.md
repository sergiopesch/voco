# VOCO 2026.0.54

Dependency maintenance candidate. [2026.0.53](2026.0.53.md) remains the verified
public release while this cut is reviewed and qualified.

The candidate updates Tauri, its logging/build dependencies, Geist fonts, React
types and Playwright. Tauri consumes the updated patched tray library, retaining
VOCO's immutable icon paths and measured meter frames. A stronger dependency
gate rejects a second tray version or an unpatched registry copy.

The approved Vite 8 / React plugin 6 migration uses Rolldown/Oxc and Lightning
CSS while retaining the previous explicit JavaScript and CSS output targets.
Development and CI use Node 24 LTS. Future Vite/plugin updates share a dedicated
Dependabot group so their peer requirements receive one review. No application
redesign or recognition-model change is part of this maintenance work.

The Vite 8 candidate passes 449 frontend tests and isolated renderer checks for
16 dictation, 31 microphone and 42 native-capture cases, plus branded-interface
checks. Type checking, lint, production frontend build and repository checks
also pass. The native dependency update passed 258 application Rust tests,
19 browser-host tests, 7 GLib tests, 22 focused package tests and locked
release-mode native check/Clippy before the frontend migration. Exact-package
qualification of the combined candidate remains required.

npm reports zero vulnerabilities. Cargo reports no vulnerability-class findings;
its seven unmaintained and one unsound warnings remain visible, as in .53.
The existing patched GLib provenance and regression gate remain required.

Publication requires the protected source checks, complete package validation,
isolated installation and desktop qualification, signatures, and downloaded-asset
verification. Source version metadata alone does not establish a public release.
