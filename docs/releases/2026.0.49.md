# 2026.0.49 local test candidate

This candidate is not a published GitHub release. The public Ubuntu/Debian
installer remains pinned to 2026.0.47.

- Fix first-word-only streaming in rich editors whose accessibility tree stores
  text in nested paragraphs. Confirm text and caret in the bound paragraph;
  preserve focus checks, bounded waits and explicit recovery.
- Make the microphone signal easier to see at ordinary speech levels, using
  wider bars and a more responsive display curve. Recorded audio is unchanged.
- Remove duplicate recovery-message wrapping and an unused copying DC-offset
  helper. Count transcript diagnostics without temporary text arrays and skip
  their construction when diagnostics are disabled or their queue is full.
- Add real Chromium clipboard regressions to CI and finite delivery-failure
  categories to local traces. Update architecture, troubleshooting and the local
  study guide without changing its pinned historical source catalog.

See [review and verification](../testing/rich-editor-2026-09-21.md). Physical
microphone and owner-session Codex/Wayland testing remain separate from isolated
fixtures. This candidate preserves the recognition model, thread policy and
existing capture/clipboard permissions.
