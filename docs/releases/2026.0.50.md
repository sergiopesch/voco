# VOCO 2026.0.50 — test candidate

This unpublished Debian candidate includes the .49 rich-editor delivery fix.

- The complete package includes the GNOME 46 live panel. Guided setup enables it
  for the desktop user and reports when signing out and back in is required.
  Manual APT installations can enable it from onboarding/Help or `voco --setup-panel`.
- Native fallback status appears beside the icon where supported and always in
  its menu. Stop is explicit, so repeated Stop requests cannot start recording.
- Done leaves Ready visible. Launching VOCO again presents the existing idle app;
  active dictation retains focus and capture ownership.
- Four immutable tray PNGs replace repeated temporary-file churn. Delayed desktop
  readers retain valid paths for the app lifetime.

No model, capture, cursor-delivery, thread-count or permissions-policy change.
Package hooks do not enable extensions; global desktop policy is preserved.
Other Shell versions retain the native tray. Physical microphones and the owner's
live session remain separate from synthetic isolated desktop qualification.

The public Ubuntu/Debian release remains .47. Do not merge or publish this candidate
without the required final checks and publication approval.
