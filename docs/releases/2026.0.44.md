# VOCO 2026.0.44

**Unpublished cut:** the signed tag is preserved. Review found pending-start
cancellation and terminal-caret defects; [2026.0.45](2026.0.45.md) supersedes
this candidate. No .44 installer was published on GitHub Releases.

An Ubuntu/Debian x86_64 update to first-run setup and missing-cursor feedback.
The bundled English recognition model is unchanged. Fedora, openSUSE and
Arch/Omarchy packages remain at 2026.0.43.

## Changes

- Start Test uses the default microphone; the speaker uses the system default.
  The signal band responds to captured audio, and recognition displays words
  inside onboarding. Test speaker plays a short tone.
- Finish Onboarding drains the active test before saving completion. Silence,
  denied microphone access and recognition errors remain retryable and cannot
  silently complete setup. Opening onboarding does not start recording.
- Alt+D requires a verified editable cursor. A notification explains a missing
  cursor, a password field or an unavailable accessibility probe. Test speech
  stays inside onboarding and never modifies the clipboard or another app.
- Native errors preserve their readable message for diagnosis.

## Install

Use the [latest-release command](../../README.md#get-started), or download
`voco_2026.0.44_amd64.deb` with its signed Debian checksum manifest from the
[matching release](https://github.com/sergiopesch/voco/releases/tag/voco.2026.0.44).
Existing settings are preserved. To repeat the new setup after upgrading, open
Settings → Troubleshooting → Re-run onboarding.

## Verification and limits

The [candidate record](../testing/onboarding-2026-09-20.md) records source,
renderer, real-model protocol, isolated GTK and package checks. The release's
attached validation and provenance files bind additional install/remove checks,
CI and signatures to the exact published package.

Browser onboarding tests mock capture and recognition. Isolated virtual-audio
tests do not establish physical microphone quality or audible speaker output.
The .43 multi-distribution desktop measurements do not qualify these new bytes.
Custom controls without an accessible cursor are rejected. Wayland delivery still
requires a configured input helper; completing the voice test checks recognition,
not delivery into every application. No universal compatibility or recognition
accuracy improvement is claimed.

Ubuntu 24.04+ x86_64 is the dependency baseline, with AVX2/FMA/F16C and glibc 2.39+.
Clipboard delivery replaces clipboard text and never presses Enter. Recognition
is local and English-only. The original .43 missing-text report did not retain
enough native error detail to establish its exact cause.
